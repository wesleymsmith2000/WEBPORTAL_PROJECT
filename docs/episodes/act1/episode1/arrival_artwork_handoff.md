## Purpose

This handoff defines how the opening arrival artwork for Episode 1 should be prepared for use in the webportal and vertical webtoon presentation.

The prose draft includes narration, music cues, SFX cues, and timing notes. Those are useful for later audio synchronization, but the current artwork pipeline should focus on clean visual assets that can be placed into a scrolling webtoon layout.

The main production shift:

```text
From: annotated showcase / production-board images
To: clean webtoon-ready scene panels
```

## Webtoon Placement Plan

### Scene 1: Fold Emergence

**Function:** Open the episode with mystery and scale.

Possible prose pairing:

```text
The stars did not streak.

They folded.
```

Recommended visual:

- Abstract starfield
- Fold shimmer
- Bent light
- No characters yet
- Quiet awe

### Scene 2: Dual Arrival Splash

**Function:** Establish Asterion Jump Port and the two ships.

Recommended artwork:

- Halcyon's Pontiff and Jewel of Faseleh visible together
- Asterion orbital city beneath stars
- Traffic halo and academy grandeur

Possible prose pairing:

```text
Two worlds. Two paths.
One horizon of learning.
```

Production note:

- Use a clean version without embedded labels for the final webtoon.
- Keep annotated versions in docs only as reference plates.

### Scene 3: Halcyon Exterior / Institutional Arrival

**Function:** Introduce Halcyon as ordered, elite, and procedural.

Visual direction:

- White hull
- Gold trim
- Blue resonance accents
- Large academy-linked transit vessel
- Controlled elegance

Theme:

```text
Order. Structure. Counted danger.
```

### Scene 4: Halcyon Concord Deck Interior

**Function:** Introduce Hu's world.

Recommended artwork:

- Concord deck
- White medical lights
- Tactical glass
- Floating route lattice
- Amber left-emitter warning
- Students and officers arranged with disciplined spacing

Character emphasis:

- Hu: precise, controlled, watching the calculator station
- Mira: quiet perception, route awareness
- Nokose: listening to signal/system
- Nashoba: listening to people
- Xue Hu: speaking through Mister Minkowski
- Shu: calm adult perception

Possible prose pairing:

```text
Inside, no one cheered.

Not on the Concord deck.

Beauty had rules here.
```

### Scene 5: Jewel Exterior Arrival

**Function:** Transition from institution to family vessel.

Visual direction:

- Smaller ship
- Warm gold-white-blue afterlight
- Hand-loved details
- Soft relational warmth
- Arrival should feel like a prayer, not a procedure

Theme:

```text
Trust. Relationship. Reverent courage.
```

Possible prose pairing:

```text
The Jewel of Faseleh arrived like a different kind of prayer.
```

### Scene 6: Jewel Bridge Interior

**Function:** Introduce Keru, Azura, and Eamon.

Visual direction:

- Warm bridge lighting
- Bioneural interface glow
- Polished surfaces
- Plants, brass/gold details, soft blue displays
- The ship should feel responsive and beloved

Character emphasis:

- Keru: smiling into danger, gifted pilot, warm confidence
- Azura: quiet, emotionally perceptive, monitoring people before systems
- Eamon: dry humor, affectionate discipline, reverent grounding

Possible prose pairing:

```text
Keru Maa sat in the pilot cradle with both hands inside the soft glow of the link.

He was smiling.

Not because the jump was safe.

Because fear was not the only true response to danger.
```

## Clean Art Requirements

For webportal-ready assets, preferred final images should have:

- No embedded titles
- No character-name plates
- No explanatory captions
- No decorative text boxes
- No production annotations
- No large in-image prose blocks
- No fake UI text unless it is visually necessary and minimal

The webportal should handle prose, captions, and audio timing separately.

## Rendering Guidance Going Forward

Future renders should be created as if they are final comic/webtoon panels.

Prioritize:

- Clean composition
- Character readability
- Emotional staging
- Vertical scroll usability
- Consistent ship and costume design
- Strong light direction
- Room for external captions or prose blocks

Avoid:

- Poster-like overlabeling
- Heavy UI clutter
- Embedded narration
- Decorative labels unless specifically requested
- Excessive tiny text that will not read well on mobile

## Final Production Note

The arrival sequence should communicate the central philosophical contrast of the opening before the characters ever argue:

```text
Halcyon's Pontiff arrives through order.
Jewel of Faseleh arrives through relationship.

Both are valid.
Both are incomplete alone.

W-7 begins where those two ways of surviving danger finally meet.
```
